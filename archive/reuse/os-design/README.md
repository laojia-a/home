# jclawOS · 手绘字体版（5.3.0）

这是上一版字体排版网页的定向修改，保留桌面、窗口、主题、图标、笔记及其他已有模块。
打开 `JCLAWOS-手绘字体版.html`，默认进入「外观工坊 → 字体与排版」。

## 三种中文手绘方案

- 马克笔手绘：中文标题为霞鹜漫黑；菜单、标签和笔记使用霞鹜文楷；英文标题用 Caveat。
- 钢笔手记：中文标题、菜单、笔记使用霞鹜文楷，英文标题用 Caveat。
- 自由速写：中文标题用龙藏体 Long Cang；小字、菜单、笔记用文楷；英文标题用 Caveat。

霞鹜漫黑和龙藏体不铺满小尺寸操作文字。作者对漫黑的使用范围有提醒，参见下方原始来源。
切换方案后可选择「只改标题」「标题 + 标签」「整个桌面」，再点击「预览全桌面」或「应用字体」。
预览可取消；主题、图标和字号不必随字体改变。独立数值、计时、代码及 URL 使用常规等宽文字。
原来的系统、现代和宋体方案保留在「其他字体」中。

## 加载与失败处理

本手绘版会尝试本机已安装字体，再请求所选方案的公开在线字库。首次网络加载可能较慢。
没有内嵌或附送任何字体二进制文件。打开网页时，字体资源可能来自 GitHub 公共字体仓库、jsDelivr 或 Google Fonts。
仅请求字体，不将用户笔记、试排文本和项目数据拼入请求。字体请求的普通网络元数据由服务提供商接收。
选择「仅用本机」可阻止后续的自动网络字体请求；已经发出的请求不保证立即取消，但过期结果不会被注册到桌面。

只有浏览器 FontFace 完成解码后，才注册字体并显示「本机字体已载入」「在线字体已载入」。
未完成时，样张和字体卡明确标注「替代显示」，不把系统字体假称为手绘字体。
字库加载成功不保证每一个罕见字都有字形；缺字仍由浏览器按回退顺序处理。

网络不可用时，可以在「实际字形状态」对应行选择「使用本机字体文件」，自行选择已有的 TTF / OTF / WOFF / WOFF2。
导入的文件仅在此页面内存解码，不上传、不保存到备份、不打包、不自动读取电脑字体目录。
导入文件的原始家族名称不核验，因此明确标成「导入字体（名称未核验）」。重新打开网页需要重新选择。

霞鹜文楷：https://github.com/lxgw/LxgwWenKai

## 源码

`source/hand-fonts.js`：本机探测、在线字形加载、失败状态、重试、取消代次与用户文件导入。
`source/typography-registry.js`：字体来源、家族角色、三个手绘方案和作用范围。
`source/typography.js`：字体工坊、实际状态、试排、预览和提交。
`source/typography.css`：字形角色、数值保护、字体卡片与响应式版面。
其他模块保持上一版结构。运行 `python build.py` 重新生成单文件 HTML。

## 本轮验证范围

无 Browser 插件，使用 Python Playwright + Chromium。
环境限制直接 file 导航与网络字形下载，因此通过 `page.set_content()` 载入最终 HTML 内容。
检查了 10 项分组行为：页面启动、未加载提示、用户字体文件解码、仅用本机保留导入字体、三种方案预览/取消、三种作用范围与数值隔离、应用配置、试排文本转义、五档宽度无横向溢出、无未捕获脚本错误。
检查宽度：360、390、768、1440、1920 px。
字体导入成功分支使用环境已有的中文测试字体，不作为霞鹜漫黑、文楷或龙藏体的视觉验证证据。测试字体没有打包。
**未验证**：三个在线中文字体在用户网络中的成功下载、指定字体的真实视觉效果、实际文件下载落盘、跨会话本地保存、Safari/Firefox 专项兼容。
原有桌面其他功能未作全量回归；本轮集中检查字体相关变化，没有修改 GitHub、域名或业务应用。
