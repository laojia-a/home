# CH01 物资盘点：3D 静态样稿 v0

经用户确认的方向：微缩实物摄影感，简化圆润造型、真实材质和接触阴影，轻浅景深。

本目录独立于生产构建。先审阅静态构图与材质，再决定动画和其余五幕；不修改生产 Canvas 模块、不改全站配置、不部署主站。

在本目录执行 `npm ci`、`npm run build`，从仓库根目录启动 HTTP 服务，访问 `design-studies/ch1-inventory-3d-v0/`。Three.js 与 esbuild 锁定版本，运行时不依赖 CDN。

- 复用现有电视机身与台标。
- 真实 WebGL 几何、柔光阴影、透射材质与景深后处理。
- 可切换原版定格、景深开关和画面放大。
- 物件及文字只标识物资类别，不展示虚构库存或监测结果。
- 静态场景仅在加载、窗口变化或审阅操作时重绘。

主焦点：前排采血管。后景：离心管与试剂盒。前景：耗材包与冻存管。物件的接触点与投影将作为后续动画的落点依据。

验证：本机浏览器完成桌面构图、390 × 844 小屏无横向溢出检查，以及原版对照、景深开关、放大/还原交互。没有页面运行错误。显卡驱动可能输出浮点精度编译警告，未阻止画面渲染。尚未实现或验收动作；静帧不代表完整动画完成。

`bundle.js` 与 `cabinet.css` 是本次 v0 的已构建快照，审阅时无需安装依赖。Three.js 使用 MIT 许可，见 `THREE-LICENSE.txt`。
