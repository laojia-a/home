# JCLAW TV 沉浸场景设计迭代

这里保存用户提供的两个本机 HTML 基础和后续可直接打开的单文件页面。v2已迁入`src/`生产源码，本站保留演进依据；这不表示七频道视觉已最终验收。

| 文件 | 作用 |
|---|---|
| `JCLAW-TV-polished.html` | 原有节目精修与独立遥控器版本，作为参考保留 |
| `JCLAW-TV.html` | 原有正面纵深、机身控制版本；本轮迭代基础 |
| `JCLAW-TV-material-v0.html` | 统一奶油机身、黄铜五金、按键和屏幕叠层的首版 |
| `JCLAW-TV-material-v1.html` | 移除可见页眉，建立墙面、地面和机身落影 |
| `JCLAW-TV-material-v2.html` | 调整落地关系、背景光线和按需显示的操作提示；当前审阅版 |

用户明确要求主界面不要遥控器；v0–v2 使用机身旋钮、机身按键及屏内控制。生产模板已移除旧遥控器 DOM。节目 Canvas 与业务入口没有在本轮重画或改址。

本机浏览器已观察 v2 桌面画面、旋钮换台与暂停状态。窄屏完整视觉、正式源码集成、原生 `file://`、全部频道长时间播放和用户最终视觉认可仍待单独验证。
