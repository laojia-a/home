# CH01 合同金额与分期 v10

用户认可餐谱样稿后，继续补齐最后一幕。核对 CTH 的 `src/pages/contract.js` 后发现工具实际为“合同计算器”，功能是含税单价/总价与例数换算、价税拆分、分期计划、金额大写与摘要。因此本幕不沿用原先签字盖章的“合同追踪”故事，而按实际功能制作。

## 明确的演示输入

含税单价 ¥5,300、例数 20 是本次动画自设的演示输入；示例税率 6%、分期 40%/30%/30% 对应工具当前默认项。不是实际合同，也不说明真实业务应采用该税率或付款比例。

- 含税总价：¥106,000。
- 不含税金额：¥106,000 ÷ 1.06 = ¥100,000。
- 税额：¥6,000。
- 三期：¥42,400、¥31,800、¥31,800，合计 ¥106,000。
- 人民币大写：壹拾万陆仟元整。

运算复现工具在该示例下的处理；代码出处与 SHA-256 在 `reference/provenance.json`，大写转换函数取自用户 CTH 项目。不是完整财税规则引擎验证。

## 动作

20 秒：含税单价与例数逐项显现 → 总价出现 → 价税两项展开 → 比例条拆成三期票据 → 票据逐项归入金额摘要。没有签署成功、实际付款或履约状态。

## 验证与范围

`npm ci`、`npm run build`，从仓库根启动 HTTP 服务后访问此目录。`node --test amounts.test.js` 校验价税加总、三期合计与人民币大写。浏览器检查了分期及摘要页，以及实际 390 × 844 小屏下无横向溢出、无文字重叠。
