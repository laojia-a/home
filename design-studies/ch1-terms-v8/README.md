# CH01 术语检索：MedDRA 主路径动画 v8

授权范围：在明确询问是否允许将“头痛”这一条五层名称与代码随样稿推送到私有仓库 `laojia-a/home` 后，用户回复“继续”。本次仅保存该示例及样稿，不包含完整词典，也不发布主站。

继 CTCAE 等级核对后，按 CH01 原顺序继续“术语检索”。以“头痛 / Headache”展示：检索 → 明确选择 LLT → 查看归属 PT → 逐层展开 HLT、HLGT、主 SOC。

## 数据依据

已读取并核对用户 CTH 工具配置的 MedDRA 29.0 中英文版本，仅选取此条目及一条主路径。`example.json` 记录节点名称、代码、当前状态、主 SOC 标志及源文件 SHA-256，不包含完整词典。

该例 LLT 与 PT 同名、同码 `10019211`，但属于不同层级。节点键使用“层级:代码”，不会因同码而错误合并。完整主路径如下：

| 层级 | 英文 | 中文 | 代码 |
|---|---|---|---|
| LLT | Headache | 头痛 | 10019211 |
| PT | Headache | 头痛 | 10019211 |
| HLT | Headaches NEC | 各种头痛（不另分类） | 10019233 |
| HLGT | Headaches | 各类头痛 | 10019231 |
| SOC | Nervous system disorders | 各类神经系统疾病 | 10029205 |

[MedDRA 官方结构说明](https://admin.meddra.org/sites/default/files/page/documents_insert/meddra2013_0.pdf) 用于核对五层结构的含义；具体名称和路径以上述已核对的 29.0 数据为依据。动画只展示此例的主 SOC 路径，不宣称所有条目只有一条路径，不自动编码原始病情描述。

## 动作与验证

20 秒。搜索词逐字出现、选中条目定位、节点连线逐段生长、上层节点展开。桌面沿对角线展开，小屏使用 SOC 在上、LLT 在下的纵向层级。没有连续整页横移。

在本目录执行 `npm ci`、`npm run build`，从仓库根启动 HTTP 服务访问本目录。`node --test hierarchy.test.js` 检查同码不同层级的节点不合并，以及完整五层主路径。

浏览器检查了桌面和 390 × 844 的完整路径、文字与横向溢出；未见页面运行错误。此版仍是独立动画审阅稿，未替换线上。
