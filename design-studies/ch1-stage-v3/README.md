# CH01：舞台与视觉焦点，8 秒镜头小样 v3

用户认可的方向是舞台、视觉焦点、移步换景；以原版造型、配色与动画语言为基础，不采用此前写实 3D 物件构图。

本版使用 Canvas 2D 分层投影：前后层有不同缩放与位移，近景物件可被画面边缘裁切，台标固定。它验证镜头调度，不代表已经接入完整三维场景。

## 节奏

- 0–2 秒：全景，建立物件关系。
- 2–4 秒：靠近采血管，标题和整排标签退出，突出一个物件。
- 4–6 秒：横移到离心管，前后层有视差，焦点随镜头转移。
- 6–8 秒：镜头停稳，液面有轻微余动，再显示名称和示例数值。

所有数字与五列物件沿用原版演示，不是实时库存。只完成这个短段，尚未扩展为六幕或发布主站。

## 预览与验证

执行 `npm ci`、`npm run build`，从仓库根启动 HTTP 服务访问本目录。已构建文件也随样稿保存。

支持播放、暂停、继续、重播、拖动时间，以及直接查看四个阶段。

本机浏览器检查：桌面全景/近景/停稳构图；390 × 844 无横向溢出；暂停时刻 1428 ms 在两次检查间保持不变，继续后推进至 3748 ms，8000 ms 自动停在结束帧；无页面运行错误。完整观感仍等待用户审阅。
