# BE 例数估算 v6：同一舞台上的序列编排

用户指出 v5 基本都是平移。本版取消横向传送说明页，保留同一组已溯源的示例计算，重新安排动作：

- 建立两周期、两序列关系，T/R 胶囊形符号依次落定，洗脱连线展开。
- 原位翻开参数页，依次强调字段；之后向上收拢，释放中央舞台。
- 计算结果 30 出现，再将 30 个示意人形排为两序列各 15 个。
- 根据预计脱落率调整计划入组，两序列各补 2 个暖色人形，最终各 17 人，合计 34 人。
- 镜头只有少量靠近/退回；主要变化来自内容内部的建立、编排与补足。

人形表示样本量规划，不表示真实受试者或已发生的脱落。参数、计算快照和出处沿用 v5，见 `reference/provenance.json`；依旧是工具示例，不是项目例数建议。

运行 `npm ci`、`npm run build`。本版独立预览，未替换线上，v5 保留。
