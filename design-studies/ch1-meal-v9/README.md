# CH01 餐谱计算：食材与供能动画 v9

继术语检索后继续 CH01 的餐谱计算。保留原版轻盈、暖色、简化物件风格，以称量、装盘、营养换算、供能汇总表达工具功能，不把说明页连续横向平移。

## 示例的范围与来源

选取 CTH 默认食物库中的三条条目，份量为本动画指定的演示输入，不是饮食建议或实际研究餐谱。

| 食物库条目 | 演示份量 |
|---|---|
| 煮鸡蛋 | 50 g |
| 盼盼吐司小方 | 80 g |
| 特仑苏纯牛奶 250mL | 250 mL |

画面简写为鸡蛋、吐司、牛奶；具体条目及每 100 单位的营养数据保存在 `example.json`，并记录 `src/data/foods.js` 的源文件 SHA-256。数值复现该工具的现有示例食物库，不宣称适用于所有同类食品，也未重新核验品牌当前营养标签。

`src/pages/meal-plan.js` 的 `calcNutrition` 对饮品使用 mL、其他食物使用 g；用该单位下的份量乘以条目营养数据/100。蛋白质、脂肪、碳水分别按 4、9、4 换算，再汇总。

本例：蛋白质 21.87 g、脂肪 27.62 g、碳水 54.9 g，总热量 555.66 kcal（显示 555.7），脂肪供能比 44.7%。供能条按热量比例绘制，不是营养素质量比例。本例不作“高脂餐合格”判断。

## 动作与验证

20 秒：鸡蛋称量至 50 g，吐司称量至 80 g；食材落盘，牛奶按 250 mL 展示；营养素换算与供能条逐项出现，最后汇总热量和脂肪供能比。

本目录运行 `npm ci`、`npm run build`，从仓库根启动 HTTP 服务访问。`node --test nutrition.test.js` 验证饮品体积计算、总热量、供能比与份量倍增。
