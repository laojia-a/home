# CH1 六幕连播审阅 v11

使用 `src/animations/sites/cth` 的已接入模块、统一时钟和转场适配器，不复制六套独立播放器。

节目主题顺序：研究准备（例数、合同）→ 执行操作（餐谱、血浆）→ 记录核对（CTCAE、术语）。全期 145.1 秒，自动循环。每幕原有内容完整播放，再停留、叠化至下一幕的开场卡片。

## 操作

- 默认连播，尊重系统减少动态效果偏好；暂停/继续保持当前进度。
- 上一幕、下一幕和六个标题可手动切换。
- “看衔接”从本幕转场前 0.6 秒播放，方便逐个检查六处接点。
- 整期时间轴可以暂停定位；“从头连播”回到第一幕。
- “打开已接入的本地主界面”可检查正式电视的换台、设置与键盘操作。

本目录 `npm ci`、`npm run build`。从仓库根启动 HTTP 服务访问本目录。独立样稿 v0–v10 继续保留；早期原版对照已固定引用旧库存场景，避免新顺序造成错误对照。
