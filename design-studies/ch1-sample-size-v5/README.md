# CH01 例数估算：示例参数与结果动画 v5

用户认可血浆分装小样后要求继续下一幕。本版对应 CH01 原有顺序中的“例数估算”，通过研究设计 → 示例参数 → 可评价例数 → 计划入组例数呈现工具用途。

## 数值依据

参数取自当前临床工具集 `src/pages/be-estimate.js` 的 crossover 默认示例：Power 80%、α 0.05、个体内 CV 18%、预期 T/R 0.90、等效界限 0.80–1.25、预计脱落率 10%。

用该工具当前 `crossoverSampleSize` 和 `plannedEnrollment` 实际计算：可评价例数 30、工具估算 Power 80.1575%、计划入组例数 34，两序列各 17 人。计划入组来自 30/(1−0.10)，再按两序列平衡向上取偶数。

计算代码快照及 SHA-256 在 `reference/`，来源是用户自己的 [CTH 仓库固定提交](https://github.com/laojia-a/1-git-2-cloudflare/tree/66d50252ff4ad9413456fd7651271ccea42db0d5)。只读取并复制相关计算模块，没有修改 CTH 工作区。结果是复现这个工具示例，不是具体项目的样本量建议，也不代表本次重新完成了独立统计方法验证。

[ICH M13A](https://database.ich.org/sites/default/files/ICH_M13A_Step4_Final_Guideline_2024_0723.pdf) 用于核对交叉设计、预设把握度和第一类错误、考虑可能脱落的概念。指南不为此处示例的具体数值背书。
