# 本轮验证：沉浸电视与独立动画库

2026-09-14 / JCLAW TV 2.0

## 方法

会话中没有 Browser 插件，因此使用 Python Playwright + Chromium。实际尝试 `file://` 导航得到 `net::ERR_BLOCKED_BY_ADMINISTRATOR`；未绕过策略，改用 `page.set_content()` 载入最终生成 HTML 原文。合集内部的 srcdoc 选择、嵌套预览与消息通道按交付代码运行，没有用截图替代页面。

旧 TV 参考是上一版真实网页；新布局按用户此次要求改成主画面、闲置收起、更多侧栏，不声称曾取得额外图片稿审批。目视检查真实桌面／手机截图，检查画面占比、字号和字距、图标与按钮、控件布局、表面和边框、媒体状态、侧栏以及独立三维画面的裁切与层次。

## 实际检查

| 范围 | 实际运行的检查 |
|---|---|
| 默认导航 | TV 默认频道为 BE Workbench；标题、频道号、主链接一致；无源状态为非直播 |
| 换台 | 数字键直选、左右按钮、上一频道、连续 16 次换台后的最终结果；旧场景清除 |
| 更多面板 | 四个标签、频道筛选与空结果、Escape 关闭、焦点返回、未配置工具进入设置 |
| 地址 | 含账号密码的 HTTPS 拒绝；合法 loopback HTTP 应用到当前入口 |
| 观看 | 铺满页面、转场设置、关闭装饰动画、休眠和恢复、鼠标换台后闲置收起、键盘恢复 |
| 原生媒体 | 本地生成的 WebM 实际解码、画面尺寸、播放时间推进、暂停时间稳定、静音／音量属性、视频画幅 |
| 媒体生命周期 | 切台后旧 video 被暂停、src 被移除、DOM 被卸载；回到原频道是新播放器；主动恢复片头 |
| 媒体失败 | 远程请求必须确认；损坏 WebM 显示错误并回退 SVG，不失去工具入口 |
| SVG / CSS 3D | 30 个条目分别载入，真实动画对象播放／暂停、0.5× 速率、循环进度定位；各 CSS3D 正面视角控制 |
| 三维拾取 | 实际点击卡片改变相应空间变换，不只检查按钮存在；修正透明父层抢走命中的问题 |
| 导出 | 浏览器实际下载一份 SVG，保存到测试容器，逐字与指定 SVG 原文件比较一致；源码面板与 CSS3D HTML 原文一致 |
| 合集联动 | TV 更多 → 八主题动画总目录 → 折光卡片动画 → 原导航 → TV，全程实际切换 iframe 内容 |
| 旧七主题 | 实际载入、入口内容、data-ready 与本页动画链接；本轮未重跑其原来全部业务交互 |
| 格式与清单 | 73 份 SVG 的 XML 解析；30 份动画文件 SHA-256 与 manifest 一致；无字体二进制文件 |

动画检查中的百分比定位是不同循环的归一化定位；没有宣称多动画形成一条电影时间轴。CSS 三维示例为独立图库示例，不宣称已经替换各导航原本的结构。

## 视口

TV：360×800、390×844、768×1024、1440×900、1920×1080、844×390。检查文档无横向或纵向额外溢出、主打开按钮在视口内、更多侧栏在边界内。

八个独立动画页：1440×900 和 390×844，分别查看 SVG 与 CSS3D。手机三维画面初版存在居中偏移，已改为明确的中点定位；环幕重复透视引起的过度放大已修正。

减少动态效果偏好：TV 初始停止装饰仍能换台；独立动画库初始不运行循环。

## 修正过的具体问题

1. 鼠标点击换台后焦点留在按钮，导致自动收起被错误阻止：区分鼠标和键盘焦点，收起时仍保留恢复途径。
2. 视频播放时背景 SVG 只被隐藏但仍计算：播放媒体时暂停背景动画。
3. 三维示例在小屏偏到右下：相机明确以中点锚定，按视口尺寸缩放。
4. 卡片视觉在前、透明父层却抢到点击：修正 preserve-3d 与 pointer-events，实际点击和键盘均能选择。
5. 环幕的嵌套透视令屏幕放大裁切：减少重复透视，重新匹配半径与相机深度。
6. 南京多层复用 SVG 的 ID 冲突：每层分别前缀化。
7. 动画切换后“正面查看”按钮保留旧状态：每次换示例重置视角控件；减少动态效果时同步播放按钮文字。
8. 清理提取目录中不再被资源清单引用的旧原件。

## 不能由这些检查推导的能力

- 没有验证用户电脑上双击本地 HTML 的行为、真实 file origin 下的 localStorage 跨会话保存、实际触屏设备及 Safari / Firefox。
- 在 Chromium 测试文档中，用户点击触发的全屏 API 成功；不代表微信等内置浏览器或所有平台全屏都可用。失败分支会明确降为铺满页面。
- 原生本地视频测试是真实解码，但生成样片没有音轨；检查了音量和静音属性，没有验证用户扬声器输出。
- 没有加载或验证实际远程直播源、跨域源、DRM、hls.js CDN 成功路径或真实工具站点的登录。
- 保存代码保留拒绝存储时的明确提示，本轮未把环境中的临时状态当成用户持久化成功。
- 没有性能跑分、真机帧率承诺或辅助技术全量验收。新动效不代表研究数据与真实在线状态。

测试过程未收集到未捕获的 JavaScript 页面异常。上述检查是具体范围的证据，不代替视觉喜好或产品验收。
