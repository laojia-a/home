## 各文件的职责

`motion-*.svg`：完整 SVG 文档，可作为独立矢量动画；包含自身颜色、图形和动画规则。二维透视绘制不是空间模型。

`css3d-demo.html`：需要 HTML、CSS、JavaScript 与 SVG 一起运行；保留透视、图层、视角和点击逻辑。不能只取一个 SVG 就期待保留三维交互。

`original-svg/`：从原导航页提取的实际图标／插画。静态的仍是静态；动画版在上一级文件里。

`manifest.json`：来源页面、名称、分类、作用范围、原件选择器、动画对象信息和可播放文件 SHA-256。

单页源代码查看／导出无需网络。系统偏好“减少动态效果”时，动画停在静态状态；按钮、目录与查看源码仍可用。

## 复用

```html
<!-- 保留 SVG 内的 CSS 动画；可直接作为图片使用。 -->
<img src="animations/05-nanjing/motion-01.svg" alt="金陵白昼与舟行">

<!-- CSS3D 要保留完整页面。实际项目应按部署策略设置 sandbox。 -->
<iframe src="animations/06-prism/css3d-demo.html" title="三维卡片示例"></iframe>
```

以上为实现示例，不表示已发布到线上。不要把这里的节目片头与真实直播混称。
