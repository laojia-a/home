# JCLAW TV · 沉浸换台与八主题动画库

版本 2.0 / 2026-09-14

## 打开

`index.html`：单文件完整入口，默认进入沉浸电视。八套导航和九个动画库页面均内嵌；不需要服务器、安装依赖、联网或配置 API。不要只预览源码，用桌面浏览器打开 HTML。

`motion-library.html`：同一内容的独立动画目录入口，默认展示八个主题。

`08-television.html`：电视独立页。01–07 仍是原来的七个导航主题，追加“本页动画”链接。独立页面之间的跳转需保持目录结构；完整单文件入口不受此限制。

## 电视怎么用

画面占据主屏，不再在外面铺开遥控器、长标题和节目表。底部只保留当前频道、前后台按钮和打开工具；4.2 秒无操作后收起控制条。鼠标移动、触摸或键盘操作会恢复，右上角“更多”始终可达。键盘聚焦控制时不会把控件藏起来。

- ← / →：上一台、下一台；1–7：直接选择；L：上一频道；M：更多；F：全屏。
- 横向滑动画面换台；按钮也可直接操作。正在输入或打开对话框时，不抢占数字与方向键。
- 当前工具的“打开”是独立链接，不等待换台动画。地址未配置时提示设置，不猜测本机端口。
- 连续换台以最后一次选择为准；画面、频道文字、打开链接同步更新。
- 更多 → 频道：节目表、频道搜索、全部工具直达、说明、入口设置。
- 更多 → 观看：环境光、无边框、自动隐藏、转场、装饰动画、可选轻音效、全屏和屏幕休眠。
- 更多 → 视频源：本机视频／自有远程媒体、暂停、静音、音量、画幅与恢复片头。
- 更多 → 主题 / 动画：其他七个导航、八主题动画总目录、本页动画。

初始换台音效关闭；减少动态效果时不开装饰与过渡动画。屏幕休眠只是网页内状态，不关闭电脑。环境光使用频道预设色，不采集视频像素。

## 片头、视频、直播分开

默认七个频道是各工具的 SVG 动态片头，明确标示“非直播”。不包含任何真实研究数据、节目音轨、影片或第三方直播台。

可为每个频道选择本机视频，或经确认输入自己有权使用的 HTTPS MP4 / WebM / HLS 地址。本机文件不上传。文件与媒体地址仅留在当前页面会话；从合集切出电视页会销毁该页，需重新选择媒体。

换台会停止旧播放器、移除其 src 并销毁旧 HLS 实例；返回频道时创建新播放器。媒体错误会回退片头并保留工具入口。新标签打开原工具不共享原应用权限、登录和业务数据。

HLS 优先用浏览器原生能力；不具备时，在用户明确同意后加载 `hls.js 1.7.2`。播放依赖跨域许可、编码、网络和源权限；本页不绕过 CORS、DRM 或访问控制。只有 HLS 引擎确认实时列表并开始播放才显示“直播”；普通播放、循环动画、来源类型选择都不能作为直播证据。

本轮已实测原生本机 WebM 的解码和播放。**没有验证实际远端直播源或 hls.js 在线加载成功，也没有预填不明直播地址。**

## 动画如何分别收集

`animations/01-launch.html` 到 `08-television.html` 各自是可独立查看、播放和导出的主题动画页。一个页面只运行当前选中的示例，不同时隐藏播放整套资源。

总计：**22 份 SVG 动画 + 8 份 SVG / CSS 3D HTML 示例；另外保留 51 份原页 SVG 提取记录。** 原始静态图标不冒充动画，重复用途的原件不冒称全新独立素材。

每个主题目录包含：

```
animations/06-prism/
  motion-01.svg       可独立播放的矢量动画
  motion-02.svg
  css3d-demo.html     含 SVG 表面、CSS 三维变换与操作脚本
  manifest.json      名称、来源、范围、SHA-256
  original-svg/      原页图标/插画，是否原本含动画另行记录
```

动画页支持播放／暂停、0.5× 慢放、复位、百分比进度定位、正面／透视查看、源码查看和按资源类型导出。进度条是**各对象自身循环时长的归一化定位**，不是电影统一时间轴。CSS 三维示例还可以拖动调整视角；卡片与环幕可点击选择。

SVG 本身是二维矢量格式。透视绘制的层叠图形标为 `SVG 2.5D`；需要 `perspective / preserve-3d / rotateX / rotateY / translateZ` 的组合标为 `SVG + CSS 3D`，导出为完整 HTML，不伪称独立“3D SVG”或 WebGL 模型。

这次新增的 8 个三维示例**只放在动画库**，不会把原导航重新变复杂。南京为意象插画的分层，不是城市测绘模型；天空图鉴为图层示例，不是游戏角色或场景资源。

## 本地保存和资源

工具入口、收藏沿用八主题导航的本地偏好键；观看偏好使用 `jclaw-tv:watch`。默认无外部请求，主动打开网站或连接媒体时除外。浏览器拒绝保存时提示仅本页有效。不同文件路径、浏览器、隐私模式可能影响 localStorage；不承诺跨设备或跨会话同步。

不包含字体二进制文件。手绘主题的中文字体继续使用本机字体栈，不把普通回退称为特定手写字库已加载。所有媒体均由用户选择，不打包实际节目。动画资源不包含第三方角色模型、音轨或游戏贴图。

## 源码与构建

```
src/motion-library.js               七频道与主题专属 SVG 动效
src/motion-preview-runtime.js       暂停、慢放、进度与视角
src/motion-gallery.css              独立动画页
src/common.js                      共用搜索、入口和动画链接
src/regenerate-motion-assets.js    构建时刷新动效 SVG 快照
src/generated-galleries.json       构建生成的内嵌动画页

themes/08-television.css/js         沉浸观看界面与频道/媒体状态
animations/extracted.json          已提取的原页 SVG 快照，来源另存
animations/designed.json           动效生成器输出的 SVG 快照
build_motion_library.py            八主题动画页、资源与清单
build.py                           独立导航页与两个内嵌合集入口
```

仅重新编排或修改界面，运行 Python 3：

```bash
python build.py
```

修改 `motion-library.js` 后，用 Node.js 22+ 重新生成作者动效快照再构建：

```bash
python build.py --regenerate-motion
```

`extracted.json` 是保留的原页提取快照，不会因改变导航插画而自动重新采集；更换原件时同步更新它及 original-svg，不要把旧快照当新图。读取最终 SVG 或 CSS3D 文件可直接复用，不必运行构建程序。
