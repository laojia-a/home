# JCLAW TV · 动态分镜精修

4.0.0-cinema · 2026-09-14

保留参考电视机身、CRT、遥控器、七频道导航与屏内菜单。本轮改的是原有16幕节目的矢量造型、运动编排和换台节奏，不新增操作系统、业务模块或配置中心。

## 使用

直接打开 `index.html`。这个单文件已内嵌新电视、旧七套导航、原八主题动画档案和新分镜播放器，不需要安装软件、开启服务或配置 API。

`08-television.html` / `TV-七频接收器.html` 是独立电视。其“其他主题、动画库”使用相对链接；保留源码包目录即可往返。只携带一个文件时请使用 `index.html`。

本轮浏览器环境禁止直接导航到 file://；已用同一最终 HTML 原文进行浏览器内容载入测试。用户电脑上的文件来源行为、跨会话保存仍需在实际使用环境确认。

## 看哪些变化

- CH1 合同：滚轴先留一个短停顿，随后送纸，比例标记晚于纸张出现；纸面、折角与机座分别表现厚度。
- CH1 物资：五支玻璃试管错峰落架，停止移动后液面还有少量回摆；刻度、液面、标签、反光分开绘制。
- CH2 法规学习：书页曲面从右页卷起，经过竖立中间形态，再落向左边；书签保持稍晚的摆动。
- CH3 PK：轨迹从细线延伸成层叠光带，局部亮点与尾迹沿路径经过，完成后给图形留出停顿。
- 文件、节点、证据频道也分别采用叠页扫描、节点吸附、光学镜片等动作。未配置的频道仍先显示测试卡，可点“试看片头”。

不是把所有物件一起上下浮动，也不是把速度统一调慢。每段按主体动作、细节跟进、停留和退出编排，默认时长在12–14.4秒之间。

换台改为低亮度调谐与短暂光学收稳，不再使用随机色块覆盖。换台动画可打断；工具链接立即对应当前频道，不等待动画结束。默认无音轨，按键音仍需手动开启。

## 操作

数字键1–7、左右键和CH按钮换台；屏幕、OK与底部“打开工具”进入原站点。I切换沉浸，M打开菜单，空格暂停/继续，P开关网页电视。

前后分幕和下方短条用于选择当前频道的片头。暂停状态下切换分幕会显示清晰的静态构图，不停在刚入场的空白帧。

菜单在“更多”中。画面设置原有的“每幕停留”新增“分镜节奏（推荐）”，也能用8/12/16秒统一播放；画面、文字和进度由同一时间控制，不会因修改时长而中途切断另一条循环。

## 分镜播放器与导出

更多 → 更多 → 本版节目动画库。

播放器一次只播放一幕，支持暂停、继续、重播、0.5/0.25倍速、时间拖动、上一幕/下一幕、源码查看和SVG导出。旧主题动画档案未用新动画覆盖，入口仍在更多中。

`assets/programmes/` 含16个独立SVG和 `manifest.json`，每个条目标明所属频道、标题、原始时长与动作说明。导出的SVG可在支持原生SVG动画的浏览器中独立循环。

图形采用 SVG 的路径、渐变、遮罩及原生时间动画，带透视绘制的2.5D体积表现；不是WebGL三维模型。CSS三维旧档案继续作为HTML保留，不混称独立三维SVG。

## 内容与数据边界

本地片头是用途示意，不是实机录屏、直播、试验结果或真实课程。曲线、液面、点位、比例标记均不作为研究数据，不输出等效判断、分级结果或例数推荐。

保留参考中的顺序和前三个 .top 地址：CTH、临研知视、BE Workbench。其余入口不猜测。接入菜单仍能明确选择 .com 预设，并需确认与保存。

视频输入、静音、音量、退出/换台释放保持原有功能。已使用真实本机WebM检查播放推进、片头时钟暂停和换台释放；未验证远端直播或HLS的成功接入。片头始终标为非直播。

设置使用独立的 `jclaw-tv-cinema-v4` 本地键，不自动覆盖旧v3配置；旧文件与原参考未改动。匿名页面或浏览器拒绝存储时，保存会提示受限。没有云端账户、业务数据接入或字体二进制资源。

## 编辑与构建

```
src/art/make_programs.py  16幕可编辑矢量几何、关键帧、材质与时间编排
src/programme-metadata.js 频道标题、说明和既有用途边界
src/programs.js            由上述源文件生成的SVG注册表
src/motion-clock.js        当前分幕的统一时钟与有限视差
src/app.js                 七频导航、菜单、媒体、换台和电源
src/tv.css                 机身、遥控器、响应式与局部光效
src/gallery.*              分镜播放器与导出
build.py                   输出独立版、全集、SVG和分镜库
```

编辑后运行 `python build.py`，构建使用 Python 3 和 Node.js；浏览器使用成品不需要这两项。无 npm 依赖。

实际验证的范围与限制见 `docs/改动与验证.md`。原参考在 `reference/s10-tv.html`，与上传输入的SHA-256一致。未修改GitHub、Cloudflare、域名或线上业务应用。
