## 动作设计

运动组织是“准备—主动作—跟进—停留—退出”。不同场景采用不同位移、曲线变形、时间偏移和回弹量；不是物理仿真，不声称真实流体或光线追踪。

纸张采用曲面路径的中间形态插值；玻璃容器运动与液面形变分开；轨迹逐段显现而非整块缩放；微量漂移和映光不带动工具名称。材质使用原创SVG渐变、边缘描线、有限模糊和纹理，而不是背景照片。

电视中的所有分幕动画由一个requestAnimationFrame采样时钟驱动原生SVG时间，同时定位文字入场和进度。每帧使用实际时间差；隐藏页面、菜单、手动暂停、关机或媒体播放期间不推进节目时间。返回后不会补播后台积累的时间。

独立SVG保留自己的自包含原生时间轴。关闭动态效果或系统偏好减少动态效果时，提供完成构图的静态图层；不依赖偶然暂停在某个不可读中间帧。

默认16幕时长：12、13.6、12.4、12、13.2、14.2、12.8、14、12.6、13.6、12.6、14、13、12.8、14、14.4秒。用户统一指定8/12/16秒时，按比例采样同一整段，不让不同循环互相截断。

## 视觉检查

1. 在1440×900下对照上一版和新版：机身、遥控器、顶部、下方进入工具仍保留既有位置关系。
2. 检查默认画面和沉浸画面，标题/说明/按钮不被物件视差带走。
3. 查看16个分镜的中段画面：图形、文本、渐变和路径均实际渲染，没有依赖未加载的图片。
4. 书页分别在10%、22%、29%、38%、57%、85%取帧，确认弯曲、跨过书脊和落页不是同一张静态图的平移。
5. 检查360、390、768、1366、1440、1920像素宽度：文档无横向溢出，屏幕和主打开入口位于可视宽度内，主入口位于可视高度内。
6. 在Chromium录制实际自动播放，依次观察合同送纸、试管落架、曲面翻页与PK轨迹；录像为浏览器实时播放捕获后转码，不是静帧插值或视频生成。

这些检查不能替代用户对“细腻、张力、气息”的审美判断，不宣称达到某个影视制作等级或所有设备上的帧率指标。
