# JCLAW｜八套导航制作前检查表

日期：2026-09-13。状态：待执行；方框不是已经通过的测试。

## 共同导航

- [ ] 已配置工具的完整名称是可直接打开的真实链接，不先跳说明窗口。
- [ ] 搜索结果Enter直达；预览按钮与真实外链不同，不混淆同一点击。
- [ ] 七个现有工具的名称、用途和URL逐一确认；本机入口不猜域名或端口。
- [ ] 首屏不自动进入设置、字体工坊或复杂教程。
- [ ] 所有出现的按钮都确有作用，无假实时数据、假登录和假在线灯。
- [ ] 稳定排序；非编辑模式不随访问记录移动应用位置。
- [ ] 所有拖动操作都有按钮/键盘替代；输入框不被场景热键劫持。
- [ ] 旧版笔记、绘画、窗口、空间和会话数据不自动删除；新版不把它们重新做成主功能。

## 视觉与内容

- [ ] 八套具有不同构图，不是同一卡片网格换背景。
- [ ] 真实中文、英文产品名及标点实际排版，不以短占位文案代替。
- [ ] 指定中文字体真实加载；失败时回退不冒称成功。
- [ ] 文本、按钮、搜索与工具名为代码原生内容，不烘焙进背景图。
- [ ] 图标的轮廓、视觉重量、基线、材质与交互区域一致。
- [ ] 纸纹/光晕/景深不遮盖文字；活动状态不只靠颜色。
- [ ] 不附送字体文件；外部图片、角色、音乐素材未授权项不计作可发布资产。

## 每套专属检查

### 轻桌面
- [ ] 只有一组主应用入口，不用网格、Dock和侧栏重复三遍。
- [ ] 没有窗口管理、虚拟桌面、假硬件控制或模拟启动等待。

### Doodle
- [ ] 真实中文手写标题/标签已目视确认，不是Caveat加中文回退。
- [ ] 圈注、纸边、笔触有设计，不靠随机旋转和噪点遮羞。
- [ ] 点击不误触拖动；默认没有标签物理散落和画板工具栏。

### Orbit
- [ ] 标签是稳定可读的屏幕文字层；默认不会绕轨道追逐。
- [ ] 聚焦与直达分开；最短角度、快速连切、静止模式全部正确。
- [ ] 星体大小、距离与连线不冒充科研指标。

### Dragon Ball
- [ ] 雷达、四星球、胶囊/可选人物具有正确辨识，不是泛动漫蓝光。
- [ ] 搜索结果与雷达目标真实对应；入口数量不被七颗龙珠硬编码限制。
- [ ] 无收集、升级、充能或战斗解锁门槛。

### Nanjing
- [ ] 至少三到四个南京核心轮廓逐项对照来源：墙、湖、山、林、城。
- [ ] 选择当前或历史时间状态，不把中华门历史城楼混充当代景观。
- [ ] 长江大桥不是通用斜拉桥；紫峰不附未经核对的排名。
- [ ] 压缩意象图不伪装精确地图；工具名不被景点别名替换。

### 3D卡片
- [ ] 主卡文字平直清楚，背面不藏必须CTA；所有入口另有带名称直达。
- [ ] 连续前后切换、转场中点击、拖动取消不会打开旧卡片。
- [ ] 不劫持全局纵向滚轮；平面降级仍保留所有功能。

### Zelda
- [ ] 视觉时代统一；天空群岛、遗迹和地图不是随意拼所有作品。
- [ ] 所有目的地默认开放，无开塔、体力、背包、跑图门槛。
- [ ] 手机不用强制横屏/捏合才能看到工具。

### TV
- [ ] 工具预览、录播、直播三种类型真实区分，不把循环视频标LIVE。
- [ ] 有确认的实际媒体源、使用范围、跨域/嵌入条件和播放成功证据。
- [ ] 没有媒体源时工具目录和打开按钮仍可用。
- [ ] 换台停止旧媒体，监听器/播放器释放，标题/链接/声音完全一致。
- [ ] 自动播放拒绝、静音、主动播放、缓冲、失败、结束与全屏返回均测试。
- [ ] 输入焦点清晰，CH按钮/键盘/触控均可用；模拟电源不锁住导航。

## 实际设备与异常

- [ ] 1440×900、1366×768、390×844、360px：首屏、长名称、手势与按钮。
- [ ] 200%缩放；键盘从头到尾；清晰焦点；关闭弹层后的焦点恢复。
- [ ] 第一秒立即打开工具，不等待场景素材；慢网与字体失败仍能使用。
- [ ] 减少动态效果、快速换十次、窗口尺寸变化中途，状态都一致。
- [ ] 存储拒绝和脏偏好配置可恢复；新增12/20个入口不打破布局。
- [ ] 只激活一个当前主题场景/媒体实例，不同时运行八套。

## 验收记录应分开

视觉结果：实际截图、真实字体、哪里仍不满意。

导航结果：从看见到打开的实际动作数、是否有阻塞。

技术结果：脚本错误、状态一致性、性能与降级。

外部结果：域名、登录、视频源、字体网络和下载实际成功与否。

不能将“所有按钮点过”当作视觉通过，不能将“画面好看”当作导航通过，也不将测试替身当成外部服务已接通。
