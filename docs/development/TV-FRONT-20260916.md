# 正面观看，立体感留在物件上

用户最新要求：“3D，但是界面不用扭啊。主要还是面对前面。”这条覆盖第二轮的轻透视方向。

## 修改

基于PR #14实际分支的deda50af91bb2ec456b65b5ac6096c088689427f，不使用尚未挂接到该分支的旧实验提交覆盖它。生产修改仅在src/styles/tv-shell.css。

取消整台电视的rotateY/rotateX和透视。屏幕、Canvas、台标、菜单及按键文字保持正面；鼠标移动不改变观看角度。机壳后层缩为右侧22px、底部9px的窄厚度，取消后壳与散热孔斜切，提手摆正。保留原有奶油色、双层倒角、内凹玻璃、凸起旋钮/胶囊按键、支脚及接触阴影。侧面小字收起，避免窄侧边堆字。

右侧控制、默认隐藏的辅助遥控器、七频道、16幕、换台/播放逻辑、工具地址、reference及baseline不改。旋钮指针仍然转动；停止的是整机倾斜，不是节目动画。

## 检查与画面对照

实际浏览器检查包含1440×900、1280×720、1024×768、768×1024、390×844、320×740、844×390。用DOM.getBoxModel读取机身正面、屏幕和实际Canvas的四角，确认上下边水平、左右边垂直；再将鼠标移到窗口四角及画面中心，确认屏幕坐标不变。不是只读取CSS中写了transform:none。

换台只改变指针和节目；暂停/继续、菜单保持手动暂停、沉浸进入/退出均纳入检查。检查不改播放器时间，不seek、不用静态海报替代运行页面。新截图tv-front-1440.png和tv-front-390.png取自实际播放中的HTML。
