# 小电视与换台打磨

## 本次做了什么

用户要求优化主界面的小电视与换台，并提供奶油色手绘电视作为参考。基于 main `0db8c7e304d9b5ba44c2f1c4aad1b440c3489c3c`，在 `polish/tv-shell-tuning-20260916` 实施，PR #14；不改 main、不自动部署，不扩大为操作系统或改造外部业务站点。

电视从平直屏幕包边改为有薄侧壁的奶油色机身：提手、天线、弧形玻璃内框、小面积黄铜旋钮、木色支脚。保留独立遥控器。机身控制是真实按钮：旋钮点击下一台，左右拖动每22px一档，也可用旁边的上一台/下一台按钮。频道窗、旋钮、遥控器、节目和打开链接同步更新。

换台由原马赛克消隐改为300ms横向错位和分层消隐。连续换台捕获当前屏幕合成帧，不跳回旧台原始帧；没有输入锁和额外等待。电源继续使用既有CRT收束。减少动态偏好下跳过转场，保留导航。

手机保留已有竖屏节目构图，缩薄机身包边，底部五个按钮至少44×44px；横屏去掉提手、支脚和下饰板以让出节目面积。菜单期间外部控件inert，关闭后返回原控件，保留手动暂停。

## 实际验证与限制

本地环境未提供Browser插件，使用Python Playwright及Chromium。尝试本地HTTP入口时返回 `net::ERR_BLOCKED_BY_ADMINISTRATOR`；未解除或绕过限制，改为显式 `--content` 加载构建后的真实HTML。该路径不能证明HTTP、file://入口或持久化存储正常。受限环境会如实显示存储不可用提示，截图等待提示自然结束。

已在本地执行：13项Node测试、构建/源码语法/网站边界/原始基线哈希校验；19项原浏览器流程；新增17项机身/输入检查；128帧节目Canvas像素对比；16个历史SVG的哈希、seek、冻结、恢复。新增检查涵盖真实旋钮点击/正反拖动/取消、连续换台、地址与台号同步、菜单焦点、开关机、沉浸、全屏、8种视口、模拟触屏横滑及减少动态。实际结果文件由测试输出，不把下列未测项计为通过。

**128帧比较范围有意收窄到节目本身**：机身改变会改变Canvas显示尺寸，因此先把候选Canvas的绘制尺寸明确设为该视口下原基线尺寸，再比同一时刻的完整RGBA哈希。期望值仍来自不可修改基线，未重录或放宽哈希。完整页面外观不是像素不变，另用真实前后截图检查；`parity-results.json`逐帧记录比较尺寸。

未完成：完整旧TV合集往返（源资产仍缺）；真实手机硬件、Safari/Firefox；生产站点部署与登录后的外部工具；用户对视觉的最终确认。当前复杂节目中的小字不属于本次机身改动，应在后续网站动画精修中处理。

GitHub Actions继续运行现有检查，并默认用HTTP/file入口执行 `tests/tv_shell.py --video`。其结果必须以对应提交的运行状态为准，不拿本地content模式替代。`s10-check-evidence`包含实际截图、录屏和JSON，`tv-preview`包含可运行HTML与准确源码；这些是7天保留的运行产物，不称为永久媒体归档。

## 修改位置

`src/ui/tv-shell.js`：机身DOM、旋钮指针/点击/拖动、外部焦点隔离；不保存地址、不建立节目时钟。

`src/ui/tuning.js`：现有播放器时钟驱动的换台绘制；无独立定时器或随机闪白。

`src/styles/tv-shell.css`：电视与遥控器材质、响应式、焦点和减少动态；生产频道绘图不改。

`src/runtime.js`：接入机身显示、复用switchTo、捕获合成帧并调用新换台效果；`index.html`/构建脚本同时接入样式。

`tests/tv-shell.test.js`、`tests/tv_shell.py`、`tests/parity.py`：单元、真实浏览器与节目保真检查。reference、baseline和七网站renderers无内容改动。
