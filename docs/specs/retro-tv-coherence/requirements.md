# Requirements · 复古电视视觉与交互

版本：1.0 / 2026-09-16。规格状态：待审核。实现状态以 [audit.md](audit.md) 为准，以下要求不自动代表已经完成。

## 1. 目标和已确认的要求

这是一台可以操作的复古小电视，也是七个网站的导航。用户最新要求优先于早期探索：保留认可的电视构图；主要面对前方；用合理纵深表现实体感，不扭转界面；隐藏或取消独立遥控器；控制集中在机身右侧；不要页眉和右上角更多；按钮更复古，元素与配色一致；打开或刷新先开机，再按原有节目轮播。

用户本轮要求先复盘、查外部资源、写规格和开 PR，审核后推进。因此本规格 PR 不能夹带页面修改，不允许把助手的设计判断或自动检查升级为用户批准。

## 2. 范围

包括：机身、玻璃、旋钮、四主键、刻度、扬声器、提手、天线、支脚、落影、字标、屏内操作条、节目表与设置、启动/待机/换台/暂停状态、手机适配，以及各频道与外壳的视觉关系。

不包括：重做七个网站、增加操作系统功能、统一账户、外部业务数据、临床计算、实时监控、自动给出 BE 结论、强制迁移全部 Canvas 为 WebGL/SVG、修改真实入口域名、补全 #9 的全部历史资源。原有节目内容必须保真；确需改善小字时另列对应网站任务。

## 3. 功能与表现要求

### R01 · 版本与交付一致

实施必须从审核时重新读取的实际分支开始。PR #14、main、聊天 V3 和生成图分别登记。先比较源代码和行为再选择性接入，不允许把聊天单文件直接覆盖 `src` 或回退其他提交。

交付 HTML 必须由可追溯源码构建；最终截图、录像、测试和 HTML 对应同一个提交。未入库附件只能标记为附件，不能只列一个哈希便宣称完成归档。验收：固定源提交、HTML 哈希、改动文件清单、实际回读相符。对应 D01、T01、V01。

### R02 · 正面、稳定、有纵深

机身正面、显示内容、菜单和文字保持平正；没有整机 rotateX/rotateY、鼠标跟随视角、呼吸式整机缩放。旋钮可以转，键帽可以压，节目可以动。

深度只由后壳、倒角、内凹玻璃、控件厚度、前后脚和接触阴影表达。它是近正视的插画式投影，不宣称为物理相机的严格正投影。验收：各视口实测前框/Canvas 四角，鼠标经过前后坐标不变；深度方向按 D02 检查。对应 T03、V02。

### R03 · 一套机身材质与配色

外壳、键帽、金属件、内框和印刷标识各有固定材质角色；同类部件共享颜色、边线、高光和磨损规则。不是给全页加泛黄滤镜，也不是把所有材质都改成同一种颜色。

四主键不得继续以四种等面积、高存在感的彩色糖果面并列。推荐同族象牙色机械键，仅用小面积状态标识；备用方案保留原参考的奶油主体与小色端。最终选择见 Q01，尚待审核。验收：同一组静态/按下/选中/禁用样本并排确认，物理面板不随频道换色。对应 D03、D04、T02、V03。

### R04 · 沉浸式电视，不是网页套壳

常态没有页眉、网页时钟、顶部更多、外置遥控器或悬浮手机遥控条。主要入口均在电视本体；手机允许把控件移到下方机身。节目表和设置在屏内打开，不增加外部侧栏或介绍卡。

辅助信息需要可达，但不堆在屏幕常态画面。菜单打开时必须保留明确关闭入口；无鼠标也能完成导航。验收同时检查可见画面、DOM、键盘路径，而不只是 CSS 隐藏。对应 D05、T03、T05、V04。

### R05 · 四主键真实可操作

保留电源、播放/暂停、节目表、打开工具四个功能，桌面顺序自上而下固定，手机沿相同阅读顺序排列。按钮有固定安装座与活动件；动作不移动整机或整个凹槽。

休止、悬停、聚焦、按下、松开、持续状态和不可用状态必须明确区分。外观变化不能替代实际状态变化。标签、图标与激活行为一致；不靠颜色独自解释状态。原 V3 已有分层结构，应优先调整形状、比例和材质，而非重复重写这三层。对应 D04、T02、T04、V05。

### R06 · 换台与分幕不同

七频道顺序与名称保留：临床工具集、临研知视、BE Workbench、EZCTD、BE Solo、BE Oracle、2026学习资料；分幕数仍为 6/3/3/1/1/1/1。

旋钮点击、拖动、上一台/下一台、数字1–7和左右键指向同一状态。上/下键及屏内分幕入口切换当前网站的节目，不冒充换台。拖动必须有不需拖动的单指操作替代；跨7/1循环，快速输入立即反映最后意图，不等待转场。对应 D06、T04、V06；[N09](references.md)。

### R07 · 首次进入与刷新先开机

首次绘制先呈现关闭的显像面，不能先显示节目再由延时任务盖黑。普通动态模式使用短开机序列，参考目标约1.7秒：黑屏/亮点、横线、展开、显像稳定，然后进入节目。

启动期间节目 elapsed 必须为零；启动用同一宿主时钟的独立阶段推进，不能提前消耗第一幕。每次刷新重新开机，不用上次 boot-complete 缓存跳过。保留跳过入口；不依赖网络、字体或声音完成启动。对应 D07、T04、V07。

### R08 · 启动可打断，旧动作不能复活页面

开机中关闭电源立即取消启动；等待原时长后仍保持关闭。再次开机是新的一次启动。换台、菜单、打开工具不能因启动被锁住；具体顺序按 D07。

没有失控的180ms延时回调、多个并行开机定时器或迟到转场覆盖新状态。验收必须用连续输入检查，不只截开机末帧。对应 T04、V08。

### R09 · 播放、暂停、菜单、后台分别处理

普通模式默认播放，保留当前频道内部的分幕自动切换。**不新增七频道自动轮换**。保存的“分幕自动切换”偏好继续生效；与用户播放/暂停意图分开。

用户暂停后打开再关闭菜单，仍暂停；菜单只暂停节目时间，不重置内容。页面隐藏时停表，回来不跨过多幕。暂停应真的冻结主体画面；播放必须有主体像素变化，不以帧计数或进度条移动代替。对应 D07、T04、V09、[N03](references.md)。

### R10 · 减少动态不等于无解释停播

遵守系统减少动态偏好：以短淡入代替展开/抖动，显示清楚的播放入口及原因。用户主动播放后可看节目，但不恢复整机扭动。

修正 V3 中首次主动播放从72%静态预览位置续播的问题：初始系统减动态静态帧只作海报，首次主动播放从本幕0开始；用户手动暂停后继续则不得重播。系统偏好变化不能覆盖用户主动暂停。对应 D07、T04、V10、[N07](references.md)。

### R11 · 外部工具导航保持真实

已配置入口必须可立即打开，不等开机、换台或演示盖章结束。未配置频道继续允许看预告，打开时进入地址配置并说明原因，不编造网址、在线状态或自动启动本机程序。

沿用实际 `.top` 和已保存有效地址；新标签打开使用安全链接属性，不把用户输入拼进脚本或未经校验的HTML。实际临床软件和登录不在本导航验收范围。对应 D06、T04、V11。

### R12 · 字体、图标与印刷标识统一

物理控件采用一套短标签字形、一套数字刻度、一套图标笔画；手绘字只在小范围字标/注释使用。中文可读性高于“手写感”。不得写了字体名称就声称字形已加载；记录实际使用字体和回退。

印刷标签不随状态变成另一种字体、长度或颜色家族。可变操作文案与 toggle 语义择一一致实现；推荐方案详见 D04。字体二进制不入库、不作为交付文件。对应 D03、D04、T02、V12、[N01](references.md)。

### R13 · 屏内操作层与节目分开

机身是实体材质，屏内菜单是发光画面，二者不需要相同立体阴影。它们共享色温、字形和状态意义，而不是复制同一组胶囊按钮。

保留节目表、画面、接入、说明的能力与表单草稿；不为视觉简化删除设置。底部辅助条仅按需出现，聚焦时不自动消失；不遮挡主要节目标题、关键数值和打开入口。对应 D05、T05、V13。

### R14 · 不破坏节目差异与示意属性

保留16幕动作、信息与顺序；暖纸工具、深绿课程、深色曲线及其他预告色可以不同。统一的是外壳和操作语言，不是用一层黄色滤镜把所有频道染色。

演示数值、印章、分级卡、进度等须继续明确为示意；不能改成真实业务承诺。现有小字或低对比记录到网站专项，不用扩大阴影/扫描线掩盖。对应 D08、T06、V14。

### R15 · 响应式保持同一台电视

桌面右侧控制，手机下方控制；不能在手机退化成彩色游戏手柄或仅提示使用电脑。尺寸变化可收起非必要装饰，但必须保留电源、播放、换台、节目表和打开功能。

目标视口见 D09。主要触控目标至少44×44 CSS px；这是本项目自定目标，不冒称 WCAG 2.2 AA 的24×24最低条款。小窗口优先重排和合理滚动，不能用 overflow:hidden 掩盖被截断的控件。对应 T05、V15、[N02](references.md)。

### R16 · 键盘、对比、减少闪烁

可见文本常规对比目标至少4.5:1，大文本至少3:1；关键图标/焦点与边界按各自功能检查。渐变、高光叠加后按实际最弱区域检查，不只算主色。

对话框有名称、焦点进入与返回、Tab约束和外部不可交互；输入框的数字不能换台。启动/换台不做全屏高对比闪白或反复红闪。不可用状态仍应读得清楚。对应 D04、D05、D07、T05、V16、[N04–N06](references.md)。本规格不宣称已经完成 WCAG 合规认证。

### R17 · 可离线、可维护，不增设不必要引擎

默认保持现有原生HTML/CSS、Canvas节目与单一宿主时钟。不因“3D”立即上Three.js、不为手绘随机重画每帧、不把原生按钮做成整图热点。

字体、外部图片和CDN失效不得影响本体启动和菜单。后续成品提供自包含HTML，源码中保持网站模块分离。结构整理与视觉改动分别比较、分别提交。对应 D10、T01、T03、V17。

### R18 · 审核与证据

每项实现都要给出同版本的截图、操作录像或状态记录；前后画面视口、时间点和字体条件一致。生成图只作视觉探索，永远不能当浏览器截图。

测试通过不代表复古感获认可。须先批准Q01–Q03，再确认控件小样与整机，最后批准交互成品；没有用户审核记录就不得合并实现或上线。对应 D11、T00–T07、V18。

## 4. 完成标准

R01–R18都能指向实际证据；三份规格对控制顺序、播放状态、尺寸、颜色和行为无冲突；文件、源提交和截图对应；残留风险明确写出。审查仍未批准的内容保留为待办，不以“已规划”替代“已实现”。
