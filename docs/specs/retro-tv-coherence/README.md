本批只提交复盘、来源、需求、设计和任务，不修改生产页面，不合并或部署。不是又一版 HTML，也不是用效果图代替交互实现。

## 先看结论

现有 V3 已有固定凹槽、侧壁、移动键帽，已取消页眉，开机时也已停止节目计时。问题不能再概括为“加阴影、拆三层、加开机”。真正需要调整的是：四个等权重彩色胶囊键的造型与用色；机身、金属、刻度、图标和字体缺少共同约束；桌面与手机的控件家族不够一致；仓库与聊天单文件尚未采用同一条交付路径。

建议保留已认可的正面大屏、右侧控制、七频道和16幕，先审一组按键实物样式，再扩展到整台电视。不要再次重写全部节目。
