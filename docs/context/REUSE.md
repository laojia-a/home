# 历史资产复用范围

这里保存“值得学什么”，不表示相应大文件已入库。实物状态见STATUS，不能用本文件替代源码。

## 八主题研究

轻桌面：固定位置、清晰独立图标、直接启动；不用窗口管理。Doodle：成熟纸面索引、真实中文字形、有限圈注反馈；不用重力乱飞或画板。Orbit：固定标签、明确索引、可选聚焦；不让目标持续移动。

龙珠：雷达、胶囊、四星球的物件语言；搜索/点位相互反馈，无收集解锁。南京：城墙、山水城林、湖面与城市天际线；城市意象不是准确地图，历史与当代建筑不能随意混用。3D卡片：厚度、透视、遮挡和运动一致性，平面名称索引可直达。塞尔达：天空岛/遗迹/地图探索氛围，无生命值/耐力/开塔门槛。TV：大屏节目、数字换台、前后频道与独立打开；其他内容进入更多。

这些是历史方案的设计意图，不代表每一件交付都已实现到位或已获用户认可。

## 动画库

早期沉浸包声明22个SVG动画、8个CSS三维示例及51个原页SVG提取记录。应按文件清点而非照抄数量，静态提取图标不算新动画，透视2D不算WebGL。每主题单独预览、源码和导出；动画使用方式和许可仍需核验。

动态分镜包另外包含16幕节目SVG。当前生产S10是Canvas16幕，不能把两种“16幕”混作同一实现。保存历史SVG用于形态/动作借鉴，不自动替换Canvas。

## 主题、图标、字体

jclawOS阶段有五主题、四图标风格（Prism/Contour或mono/Pixel/Doodle）；资源可脱离OS复用。保留独立手绘路径、纸纹、颜色token和状态图标，不为复用图标重新引入桌面应用。

字体方案涉及系统无衬线、中英文混排、宋体、霞鹜文楷/漫黑、龙藏体及Caveat等历史候选。它们是方案或外部加载引用，不代表已在所有浏览器成功加载；不打包字体二进制，不提供系统内字体文件。加载和回退的代码/说明可归档。

## 媒体与验证经验

旧TV曾有本机视频、远程源、音量/静音、换台释放与错误回退。当前S10主线没有因此自动继承真实媒体能力。HLS/远端直播未获全量验证，不写LIVE；历史本机播放录屏只能证明相应环境中的旧版本。

## 复用准则

先读出处、目标和限制；提取到对应网站模块；统一当前宿主时间/生命周期；测试停播、切换和清理。不可整段拷贝旧全局runtime，只因某个旧动作好看就覆盖当前导航。
