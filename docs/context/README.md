# 对话成果总索引

这份目录用于让新工作区仅凭仓库接续，不必反复询问用户或要求其从旧聊天搬附件。记录依据是当前可见对话、用户提供的s10参考、实际可读取交付文件及GitHub核验；不是完整逐字聊天导出。被省略/不可见的片段不擅自补造。

## 三类证据不能混用

用户明确请求/否定决定产品边界；源文件证明当时有哪些代码与设计；实际测试记录只能证明对应版本和环境中执行过的行为。助手说“高级”“全部已测试”“已经保留”不是独立证据，文件名含“终稿/精修/vNext”也不是用户验收。

## 资产状态约定

- `in-main`：能在当前仓库路径读取实际文件。
- `located-not-imported`：交付附件已定位，但字节还不在仓库，不能伪装成可用链接。
- `derived`：从原始资产提取/重建，必须保留源哈希、方法与差异。
- `rejected-reference`：记录失败教训，不作为生产母版。
- `historical-unverified`：旧说明或示例，未在本轮重新验证。

完整归档需要实际资产和说明一起到位。仅补本文档，不能宣告所有网页、动画和媒体已沉淀。
