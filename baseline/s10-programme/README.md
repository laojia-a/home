# JCLAW TV · S10 节目精修

2026-09-14 / Programme edition 2.0

## 使用

直接用浏览器打开 `index.html`。这是自包含 HTML，默认进入本轮 TV，原 s10 和此前 TV／八主题／动画库均可从“更多 → 更多”进入。切到档案后，右上角有“返回新版电视”。无需服务器、安装依赖或 API。

`S10-节目精修.html` 是约 85 KB 的独立新版页面。单独保存也能播放全部本轮节目；其中档案入口需要与本包 `reference/`、`archive/` 目录放在一起。只希望使用一个文件时选择 `index.html`。

工具网站需要网络；本地动画、搜索、节目切换不需要网络。聊天软件的静态预览可能不执行脚本，应保存 HTML 后用浏览器打开。

## 保留与更新

以用户提供的 `s10-tv.html` 为视觉及节目组织依据，不采用后来被否定的“左插画、右介绍卡”版。保留薄奶油色边框、原实体遥控器、大屏节目、七频道、屏内菜单、CRT 缩线开关机和点击屏幕进入工具。

本轮更新的是节目画面和必要的交互修复，不增加桌面系统、待办应用或统计计算功能。

## 操作

- 数字 1–7：换台。
- 左右方向键：前后频道；上下方向键：前后分幕。
- 空格：暂停／继续。切换分幕时，如果当前暂停，会显示可阅读的稳定画面。
- Enter 或点击节目画面：打开当前工具；屏幕下沿也有独立按钮。
- M 或 Ctrl / Command + K：打开频道菜单。
- P：网页电视待机／开启，不是电脑关机。
- I：沉浸观看；Escape 退出沉浸或关闭菜单。
- F：请求浏览器全屏。被宿主拒绝时会提示。

遥控器左侧原 `VOL` 实际在参考中改变亮度。本版明确改为“分幕”，用于前后一幕；没有虚构音量功能。亮度在“画面”菜单调节。手机底部提供电源、换台、播放和更多操作。

自动收起的只有屏幕下沿操作条；鼠标移动、触摸或键盘焦点可唤回。焦点停在操作条上时不会隐藏。菜单打开时节目停表，关闭后继续。

## 参考内容与示意边界

原参考保存在 `reference/s10-tv.html`，文件字节未修改。下述是新版主动做出的内容区分，不回写原参考：

- `LIVE` 改为“本地动画／片头预告 · 非直播”。
- 合同盖章改为“示意”，不声称已签署、真实研究中心或已经归档。
- 物资百分比沿用参考的演示比例，去掉“已自动生成采购单”的业务状态断言。
- `n=48`、`986 kcal`、`约52%` 沿用参考，仅作为排版与动画样例，不是本页计算结果或临床建议。
- 不良事件卡片不把某一受试者自动判为 G2，也不自动关联真实数据库条目。
- 术语幕保留 headache / 头痛的来源示例；不假装连接实时 MedDRA 数据库。
- 法规课程幕不把参考的“2025 修订要点”当作最新法规信息；使用通用的“法规条文与适用范围”作为概念板书。
- Workbench 使用合成曲线，不输出写死的等效结论或90%置信区间，不提供统计验证功能。
- 后四台预告可观看，但不会因预告播放而自动启用工具网址。

这些内容用于导航节目，不是授课材料、研究结果、法规检索或真实业务状态。关于参考原文和新版的区别，以上列举而不隐瞒替换。

## 入口设置与存储

默认前三个地址沿用原参考的 `.top`；后四个为空。没有擅自切换为 `.com` 或猜测本机服务地址。“接入”支持配置全部频道、启用状态和未保存草稿提示。

保存前统一校验；拒绝 `javascript:`、带账号密码的地址以及非 HTTPS／非本机 HTTP 方案。空地址不能启用。输入框中的数字和方向键不操作频道，输入切换菜单标签后仍保留。

偏好保存在独立的 `jclaw-s10-programmes-2` 键中，不覆盖参考和旧版的存储。不自动导入旧设置，已有自定义地址需在新版填写。浏览器拒绝写入时明确提示“仅本次页面生效”，不会显示“已保存”。

没有云同步、媒体直播或原应用数据接入；既有媒体版本作为档案保留，不声称本轮重新完成那些能力的验证。

## 本轮实际检查

环境未提供 Browser 插件，使用 Python Playwright + 系统 Chromium。沿用环境允许的 `page.set_content()` 加载最终 HTML；没有更改浏览器策略、关闭安全限制或绕过本地访问限制。

检查覆盖：

1. 真实 Canvas 在间隔采样中的像素摘要变化，暂停时像素及时间完全保持，继续时再次变化。
2. 快速连续换台后，最后频道、遥控器选中状态和目标链接一致；没有通过锁住输入丢弃后续按键。
3. 连续开关机、待机时换台保护、开机后清理旧转场。
4. 菜单停表、键盘输入不换台、跨标签保留草稿、未保存关闭提示、地址校验。
5. 未接入频道的预告和“配置入口”，单次打开意图的 URL、`target`、`noopener noreferrer`。
6. 浏览器拒绝存储时的提示；没有把这个分支称为实际本地文件持久化成功。
7. 减少动态效果时以稳定帧开始，用户主动播放后可继续。
8. 实际全屏进入与退出，以及7种视口的页面边界。
9. 已在最终整合页实际进入原参考和此前完整合集，再返回新版换台。

交互脚本18组检查通过；另核对整合页档案往返。16幕分别查看实际浏览器渲染，没有收集到脚本或绘制错误。检查的尺寸为360×800、390×844、768×1024、844×390、1366×768、1440×900、1920×1080。

视觉检查期间修正了以下问题：曲线的前导点原先与按弧长绘制的线端不同步，已统一为同一时间坐标；手机版频道OSD原先遮住标题，已移回顶部并临时替代台标。印章提起后的淡出也提前，避免悬在合同标题上遮挡阅读。针对手机横屏又调整了底部遥控区与画面边界。

录屏是连续采样真实网页播放后按实际采样时间编码；未生成补间运动。录屏采样帧率低于浏览器动画刷新率。

**未验证**：用户设备的 `file://` 加载策略、真正跨浏览器会话的持久化、外部站点在线与登录、Safari / Firefox 真机、原生辅助技术、旧档案中所有历史功能。技术测试不代表用户已经认可设计，也不代表业务计算已验证。
